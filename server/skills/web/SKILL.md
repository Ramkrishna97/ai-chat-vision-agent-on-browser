# Web and Node projects
Description: Create and verify JavaScript, Node, and small web applications.

Use write_file to create complete files. A single .js, .mjs, or .cjs file can be executed with run_project. For package projects, use run_command for npm install, npm test, and npm run build inside the project folder. Keep dependencies small. For a browser app, build it and inspect the generated output; if a browser is available, verify the interface there. Report what was actually run.
