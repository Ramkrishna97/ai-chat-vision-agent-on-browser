# Build and verify
Description: Plan, create complete files, run the result, and report evidence.

1. Make a short plan and choose the smallest useful project structure.
2. Use write_file for whole source files. Use list_files and read_file to inspect existing work before editing.
3. Use run_project after writing code. If it fails, read the error, fix the file, and run again.
4. Show the actual command, exit code, and important output. Never claim a result was tested when no run succeeded.
